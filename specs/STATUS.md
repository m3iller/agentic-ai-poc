# Implementation Status

Shared ledger between `spec-agent`, `java-agent`, and `dotnet-agent`. Two parallel implementations
are being built against the same specs — Java (`java/`) and .NET (`dotnet/`) — each tracked in its
own column pair. `java-agent`/`dotnet-agent` update their own columns after finishing a feature;
neither touches the other's. `spec-agent` checks both before rewriting a spec so in-progress/done
work in either stack doesn't get silently invalidated.
